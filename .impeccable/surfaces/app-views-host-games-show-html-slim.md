# Surface brief: game screens (host stage + phones)

Mode: Experience on the host stage (the room watches it), Operate on phones (one private task at a time).

Audience and job: the host runs the night from a TV-shared laptop. Players glance at phones in dim light, see their secret, vote and pass backup phones along.

## Direction contract

THESIS: Every secret is a note passed in class. Phones hold a folded note that you unfold to read and fold before passing on. The stage is the notebook page the whole room is reading. It refuses the dark neon, space-and-glow social-deduction look.

OWN-WORLD: Light mode is college-ruled notebook paper with a red margin line, ballpoint-blue ink, and yellow and pink highlighter swipes that own whole blocks. Dark mode is a black-paper sketchbook with gel-pen ink in the same hues. Display type is Shantell Sans (hand-lettered, informal axis) and body type is Atkinson Hyperlegible Next. Tape strips hold things down, the join code is written big in marker, and players are roster lines with animal stickers.

STORY: The room sees one page per phase: a class roster to sign, "the note is going around", the vote tally in pen strokes, and the highlighted winner. Phones do one thing: unfold, vote, or pass.

FIRST VIEWPORT: The host lobby is a taped notebook page. The code is hand-lettered across 60% of the width with a highlighter swipe behind it, the QR code is taped at the right, and the roster lines fill below with animal stickers as people join. Start sits under the roster in ballpoint blue.

FORM: Passed Notes (the model's pick, #1 on my ordered list), seed key 0b454629.

Signature interaction: the note fold. Revealing unfolds a creased note (clip-path and rotate on the fold), and "Got it" folds it shut before the next pass.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
