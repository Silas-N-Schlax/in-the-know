# Avatars

A game can have up to 20 players, and each one gets a different animal. Save each image as a square PNG in this folder, named exactly as shown in the File column. Transparent backgrounds work best, since the app puts each animal on its own colored sticker.

The PNGs here now are simple placeholders drawn by `node script/draw_placeholder_avatars.mjs`. Replace any of them with your own art using the same file name. If one is missing, the app shows a broken image instead of crashing.
